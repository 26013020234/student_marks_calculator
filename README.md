# Student Marks Calculator 📝

## About the Project
The Student Marks Calculator is a simple Python program that calculates a student's total marks, percentage, and pass/fail status based on marks entered by the user.

## Features
- Takes student name as input.
- Accepts marks for three subjects.
- Calculates total marks.
- Calculates percentage.
- Checks whether the student has passed or failed.

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code or any Python editor.
3. Run the Python file.

```bash
python student_marks.py
```
